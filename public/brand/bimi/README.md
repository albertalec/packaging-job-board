# BIMI logo assets

Hosted files for inbox sender avatars (Gmail, Apple Mail, Yahoo).

| File | Purpose |
| --- | --- |
| `logo.svg` | BIMI logo URL (`l=` tag). SVG Tiny PS 1.2, navy roundel crop marks. |
| `certificate.pem` | Mark certificate from your CA (`a=` tag). **Do not commit** — add locally after purchase, then upload to Vercel or host here. |

Public URL after deploy:

`https://nicheboardjobs.com/brand/bimi/logo.svg`
