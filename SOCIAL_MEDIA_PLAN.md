## 1. Purpose

This plan governs organic social presence for **Niche Board** — primarily **LinkedIn** at launch, with the same message house extended to communities and future channels. Social is a **distribution and education** layer, not a primary acquisition engine until SEO, alerts, and employer pins prove out.

**North-star on social:** Contrast + one proof + one CTA. No job-spam dumps. No growth-hack energy.

---

## 2. Platform overview (LinkedIn)

**Niche Board** is a network of precision job boards for specialists.

**Tagline:** The right jobs, not all the jobs.

**One-liner (headline / About):**

> Niche Board builds specialty job boards for professional niches too narrow for broad platforms like LinkedIn — updated daily from employer career sites, with candidates applying directly on the company ATS.

### What we are

- A **network of niche job boards** — one board per specialty (e.g. Packaging, Business Continuity)
- **Daily ATS ingest** from employer career sites (Workday, Greenhouse, Lever, etc.)
- **Candidates apply on the real listing** — no fake apply wall, no profiles or messaging
- **Employers pin live listings** they already have — $100 / 30 days on the Packaging board

### What we are not

- A LinkedIn or Indeed clone with “niche” as a filter
- A catch-all industry board (e.g. plant ops mixed with package development)
- A career network with profiles, messaging, or resume databases

## 8. Content pillars (map every post to ≥1)

From [`MARKETING.md` §4](MARKETING.md#4-positioning-pillars-every-piece-of-content-maps-to-1):

1. **Classification** — Specialist titles only; we drop the noise incumbents keep.
2. **Freshness** — Daily ATS ingest; dates matter.
3. **Apply-out** — Candidate finishes on the employer ATS.
4. **Precision buy** — Employers buy a niche audience, not “jobs traffic.”
5. **Simple commerce** — Pin what’s already live; no second posting workflow.

Content that only says “find your dream job” or “post jobs fast” fails these pillars.

## 9. Content types & cadence

### Near-term priorities (ordered)

1. **LinkedIn Company Page** — About, tagline, logo lockup, link to hub
2. **Packaging R&D / package-dev communities** — same message house; participate, don’t spam
3. **Fresh listing shares** — 2–3/week with OG preview when inventory warrants ([Grok plan — Lane A](SOCIAL_LINKEDIN_GROK_PLAN.md#lane-a--new-job-highlights-board-led))
4. **Industry pulse from X** — 1–2/week trend bridges ([Grok plan — Lane B](SOCIAL_LINKEDIN_GROK_PLAN.md#lane-b--industry-pulse-x-led))
5. **Employer education** — who sees a pin, what it costs, link to `/sponsor`
6. **Hub / network posts** — light until 2+ verticals live

### Post templates

| Type | Structure | Example hook |
| --- | --- | --- |
| **Contrast post** | Contrast line + specialty + CTA | “Package development — not plant ops. Browse roles at CPG brands →” |
| **Fresh role share** | Role title + employer + contrast or proof + link | “New: Senior Packaging Engineer at [Employer]. Apply on their career site →” |
| **Proof post** | One pillar + one fact + CTA | “Updated daily from employer ATS — not stale reposts. Get alerts →” |
| **Employer post** | Audience precision + pin mechanic + price + CTA | “Reach packaging engineers, not the whole plant. Pin your live listing — $100 / 30 days →” |
| **Network post** | Niche Board + specialty boards + CTA | “One board per niche. Packaging is live. Browse specialty boards →” |

### Out of scope until inventory proves out

- Paid social / candidate acquisition
- Podcast or conference sponsorships
- Volume SEO blog content repurposed as filler posts
- Daily job dumps or “50 new jobs!” aggregates
- Unverified metrics (candidate counts, open rates, “hire in X days”)

## 15. LinkedIn drafts — X + Grok (current events)

**Operational plan:** [`SOCIAL_LINKEDIN_GROK_PLAN.md`](SOCIAL_LINKEDIN_GROK_PLAN.md) — weekly mix (job highlights vs X industry pulse), relatable hooks, workflow, and `postType` mapping.

Use **X** for timely niche conversation and **Grok** (xAI) to draft LinkedIn posts that follow this plan’s voice. Posts are **drafts for manual review** — nothing auto-publishes to LinkedIn.

**Email delivery:** set `SOCIAL_DRAFT_TO_EMAIL` on Vercel — drafts arrive Tue/Thu (and after ingest when configured) via `/api/social/linkedin-digest`. No local CLI required.

### Flow

1. **X recent search** — vertical-specific queries (packaging engineers, BCM/DR, etc.)
2. **Board context** — live job count, optional freshest role link
3. **Grok** — synthesizes contrast + proof + CTA with one current-events angle
4. **Review** — run the pre-publish checklist (§12) before posting

### Commands

```bash
# Local draft (dry-run when SOCIAL_DRY_RUN=true or --dry-run)
npm run social:linkedin-draft -- --vertical=packaging
npm run social:linkedin-draft -- --vertical=packaging --postType=fresh-role

# Cron/API (same auth as alert digest)
curl -X POST -H "Authorization: Bearer $ALERTS_CRON_SECRET" \
  "https://packaging.nicheboardjobs.com/api/social/linkedin-draft?vertical=packaging&dryRun=true"
```

### Env vars (see `.env.example`)

| Variable | Purpose |
| --- | --- |
| `X_BEARER_TOKEN` | X API v2 recent search |
| `XAI_API_KEY` | Grok chat completions |
| `GROK_MODEL` | Optional model id (default `grok-3`) |
| `SOCIAL_DRY_RUN` | Skip persisting drafts when `true` |
| `ALERTS_CRON_SECRET` | Auth for `/api/social/linkedin-draft` |

Draft history is stored in `data/social/{vertical}.json` locally or Upstash Redis in production.

## 12. Quality bar (pre-publish checklist)

Before any social post goes live:

- [ ] Tone: friendly + trustworthy + lightly fun — not eager or hype-y
- [ ] Correct brand for surface: **Niche Board** (hub/network) vs **Packaging** / **Packaging Jobs** (vertical)
- [ ] Maps to ≥1 positioning pillar
- [ ] Specialty explicit; contrast (“not …”) present on packaging content
- [ ] Apply-out or pin-existing-listing clear when relevant
- [ ] No unverified metrics
- [ ] Single primary CTA
- [ ] Links use canonical host (`packaging.nicheboardjobs.com` or `www.nicheboardjobs.com`)
- [ ] No banned names (Nicheboard, Nicheboard Jobs, etc.)

---

## 13. Success signals (social)

Track qualitatively and via referrals — not vanity alone:

- Click-through to board job pages and alert signups from social
- Employer inbound mentioning LinkedIn or a specific post
- Qualitative: “these are the right people” from employers

**Ignore as primary goals:** raw impressions, follower count without engagement, likes without clicks.
